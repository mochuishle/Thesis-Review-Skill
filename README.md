# Thesis-Review-Skill



这是一个用于**计算机类学科中文学位论文与毕业设计**评审的Skill。

是的，它蒸馏了一个大学教师数年的经历，这也许可以从评审的视角帮你更好的修改论文。

它会提供论文内容、工程实现、实验可信度、结构逻辑和格式规范等方面的评审意见。



## 一些唠叨：

很多论文的问题，并不只是写得不好。

我想说的是，你对待毕业论文的态度，也许和你的生活有一丝联系。

这个论文只是对你这几年经历的一次表达，它不属于其他任何人。



论文可以无数次去修改，实验结果可能不如预期，系统可以反复重构，这些都不重要。

问题往往不在于不会做，而在于迟迟没有开始。希望当你意识到应该去做一些事的时候就要动手去做。

只要你去尝试了，事情都会变得清晰，也相信你一定能做得到。
